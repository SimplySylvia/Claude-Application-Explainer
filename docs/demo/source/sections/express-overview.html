What is Express?

Express is a minimal web framework for Node.js: it routes HTTP requests to your functions and gives you helpers for reading requests and sending responses. Shopfront's whole API (/api/…) is one Express 4 app. Sources: expressjs.com, Application (4.x API), server/index.js.

In one paragraph

  • An Express app is a request handler for Node's HTTP server. You build it from a stack of middleware functions that run in order.
  • Each middleware gets the request and response, and either answers or calls next() to pass the request on (Using middleware).
  • Routers group endpoints under a path prefix, so each resource gets its own file.

The problem it solves

  • Plain Node http hands you raw requests. Express adds URL routing with parameters, body parsing, and helpers like res.status(201).json(…).
  • It stays unopinionated: no ORM, no project layout, so apps choose their own (Shopfront uses pg directly).

Compared with

  • Node's http module: what Express wraps; app.listen() creates the server for you (docs).
  • Express 5: the current major. Same model, but async errors are handled for you and route-path syntax is stricter (Migrating to 5). Shopfront is on 4.

How Shopfront uses it

  • One app with JSON parsing, three routers (products, orders, admin), one auth middleware, and Postgres behind it (usage map).
  • The React client doesn't call it yet; tests do, through supertest. The repo doesn't record why Express was chosen.
