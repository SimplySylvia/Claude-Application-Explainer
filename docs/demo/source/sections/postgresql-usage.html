Where Shopfront uses PostgreSQL

PostgreSQL is Shopfront's only data store, reached from the Express API through one shared pg pool. There are 4 queries in total (git grep -c "db.query" server), two tables, and no schema, migrations, or seeds in the repo. Sources: server/db.js, server/routes/, package.json:10.

Placing an order: the handler calls db.query with the SQL and a values array, the pool lends it a connection, PostgreSQL runs the insert, and the result's rows come back to the handler. The guided walkthrough follows steps 1–5.
