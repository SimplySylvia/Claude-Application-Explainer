Local development

How to get Shopfront running locally and the day-to-day loop. Every command here was checked against the repo's scripts.

1 · Set up your machine

StepCommand / notes
Install Node 20Matches FROM node:20-slim in the Dockerfile
Install dependenciesnpm install
Point at a databaseSet DATABASE_URL to a local PostgreSQL with products and orders tables. There are no migrations or seeds in the repo.

2 · Daily loop

TaskCommand
