TermMeaning (as used in Shopfront)Where it shows up (repo path)

Code & config
requireStaffExpress middleware that returns 403 unless the staff header is present. Guards /api/admin.server/auth.js
createOrderHandler for POST /api/orders: validates the cart, inserts the row, returns the id.server/routes/orders.js
newAdmin / VITE_FLAG_NEW_ADMINFeature flag that adds the /admin route. Set with VITE_FLAG_NEW_ADMIN at build time.client/src/flags.js
DATABASE_URLPostgreSQL connection string read by the pool.server/db.js
SSO proxy / SSO (single sign-on)Company proxy in front of the app that, per a code comment, identifies staff.server/auth.js
React Router / createBrowserRouterThe client-side routing library: createBrowserRouter maps URLs to page components. Not the same as an Express router.client/src/routes.jsx
ViteThe client's dev server (port 5173) and production bundler. It inlines VITE_* variables at build time, which is why /admin only exists in builds made with the flag on.package.json, client/src/flags.js
Express
ExpressThe Node.js web framework Shopfront's API is built on: one app, routers per resource, and middleware. See the Express deep dive.server/index.js
app.useRegisters middleware or mounts a router at a path prefix; matches any HTTP method, and runs in the order registered.server/index.js:7-10
MiddlewareA (req, res, next) function in the request pipeline that responds or passes the request on.server/index.js:7-10
Router (as in express.Router)A group of routes mounted at a path prefix.server/routes/
express.jsonMiddleware that parses JSON request bodies into req.body.server/index.js:7
Error-handling middleware / Error middlewareA four-argument (err, req, res, next) function that turns errors into responses. Not used in Shopfront.docs
Unhandled rejectionA rejected promise nobody catches; on current Node versions it crashes the process.docs
supertestTest library that sends HTTP requests to an Express app in-process.test/orders.test.js
fetchThe browser API for HTTP requests; check response.ok for errors.MDN
pg / node-postgres / PoolThe Postgres client; one shared pool from DATABASE_URL, used through db.query with $1 placeholders.server/db.js
PostgreSQL
PostgreSQL / PostgresThe relational database that stores Shopfront's products and orders. See the PostgreSQL deep dive.server/db.js
Parameterized query / Parameterized SQLSQL with $1, $2… placeholders and a separate values array, so values are never read as SQL. Every Shopfront query is one.server/routes/orders.js:6
RETURNINGSQL clause that makes an INSERT or UPDATE send back columns of the rows it changed, such as a generated id.server/routes/orders.js:6
TransactionSeveral statements that succeed or fail together (BEGIN … COMMIT, or ROLLBACK), run on one checked-out client. Not used in Shopfront yet.docs
SQLSTATEThe five-character code on every PostgreSQL error (err.code), e.g. 23505 for a duplicate key.docs
psqlPostgreSQL's command-line client, for running SQL by hand against a database.docs
