Where Shopfront uses Express

Express is Shopfront's whole API server: one app, three routers, one auth middleware, and Postgres behind it, in about 6 tracked files under server/ and test/ (git ls-files server test | wc -l). The React client doesn't call the API yet. Sources: server/index.js, server/routes/, package.json.

A request passes through the middleware in the order server/index.js registers it: JSON parsing, then the router whose prefix matches, then the handler. /api/admin requests go through requireStaff first. The guided walkthrough follows steps 1–5.
