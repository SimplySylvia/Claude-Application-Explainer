These tables are inferred from the queries (id is generated, items receives JSON). They aren't from the repo: check them against your real database before relying on them.

CREATE TABLE orders (

Making failures visible, in code

const { Pool } = require('pg');
if (!process.env.DATABASE_URL) throw new Error('DATABASE_URL is not set');
const pool = new Pool({ connectionString: process.env.DATABASE_URL, connectionTimeoutMillis: 5000 });
pool.on('error', (err) => console.error('postgres idle client error', err));
module.exports = pool;

serial ids keep id a JavaScript number; bigserial would return strings. The 5-second timeout is illustrative: pick one that fits your traffic.
