Concepts in code

Short examples adapted from the Express 4 guides, MDN, and the supertest README, using placeholder values. Compare each with the Shopfront file named under it.

Create an app, parse JSON, mount a router. Shopfront does this in server/index.js.

const express = require('express');
const app = express();
app.use(express.json());                 // req.body for JSON requests

const items = express.Router();
app.use('/api/items', items);            // items' routes live under /api/items

module.exports = app;                    // export for tests; listen elsewhere

Routes with a parameter and JSON responses. Compare server/routes/orders.js.

items.get('/:id', (req, res) => {
  res.json({ id: req.params.id, q: req.query.q });   // params are strings
});

items.post('/', (req, res) => {
  if (!req.body.name) return res.status(400).json({ error: 'name required' });
  res.status(201).json({ name: req.body.name });
});

Middleware that allows or rejects. Compare server/auth.js, which checks only that a header exists.

function requireKey(req, res, next) {
  if (req.get('X-Example-Key') !== '<expected-value>') {
    return res.sendStatus(403);          // stop here
  }
  next();                                // pass to the next handler
}
app.use('/api/private', requireKey, privateRouter);

Async errors in Express 4. What Shopfront's handlers are missing.

items.get('/:id/details', async (req, res, next) => {
  try {
    const item = await loadItem(req.params.id);  // your async lookup
    res.json(item);
  } catch (err) {
    next(err);                           // Express 4 won't do this for you
  }
});

app.use((err, req, res, next) => {     // four arguments, registered last
  res.status(err.status || 500).json({ error: 'something went wrong' });
});

Make an API call from the browser. How a Shopfront page would place an order.

const res = await fetch('/api/orders', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },   // needed for express.json()
  body: JSON.stringify({ items: [{ productId: 42, qty: 1 }] }),
});
if (!res.ok) throw new Error(`Order failed: ${res.status}`);  // fetch doesn't throw on 4xx/5xx
const { id } = await res.json();

Make an API call from the terminal. Against the local server only.

curl http://localhost:4000/api/products/42
curl -X POST http://localhost:4000/api/orders \
  -H 'Content-Type: application/json' \
  -d '{"items": [{"productId": 42, "qty": 1}]}'

Test an endpoint without starting a server. Shopfront's test/orders.test.js follows this pattern.

const request = require('supertest');
const app = require('../server');

test('GET an item', async () => {
  const res = await request(app).get('/api/items/42');
  expect(res.status).toBe(200);
  expect(res.body.id).toBe('42');
});
