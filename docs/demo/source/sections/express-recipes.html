Adding an endpoint, in code

A cancel endpoint in the orders router, written the way the rest of the file is, plus the error handling it currently lacks:

router.post('/:id/cancel', async (req, res, next) => {
  try {
    const { rows } = await db.query('update orders set status = $2 where id = $1 returning id', [req.params.id, 'cancelled']);
    if (!rows[0]) return res.status(404).json({ error: 'no such order' });
    res.json({ id: rows[0].id, status: 'cancelled' });
  } catch (err) {
    next(err); // Express 4 won't do this for you
  }
});

And its test, in the style of test/orders.test.js:

test('cancel needs a real order', async () => {
  await request(app).post('/api/orders/999/cancel').expect(404);
});

The status column is illustrative: the repo has no schema, so check the real table first. The test needs a database, unlike the existing empty-cart test.
