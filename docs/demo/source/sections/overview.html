What is Shopfront?

Shopfront is the storefront for Acme's online shop. Shoppers browse products and track orders; staff use the admin screens to manage the catalog. Sources: README.md, client/src/routes.jsx, server/index.js.

Who uses it

  • Shoppers: browse the catalog, place orders, and look up an order by id
  • Staff: add products through the admin catalog editor (behind the newAdmin flag)

What it does

  • Lists products and product details from PostgreSQL
  • Creates orders from a cart and rejects empty carts
  • Lets staff create products through /api/admin

Where it runs

  • Web client: a React single-page app built with Vite (client/)
  • API: one Express server on port 4000, shipped as a Docker image (Dockerfile)
  • Database: PostgreSQL, reached through DATABASE_URL
