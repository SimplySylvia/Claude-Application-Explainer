Concepts in code

Short examples adapted from the node-postgres docs and the official Docker image, with placeholder values. Compare each with the Shopfront file named under it.

Create a pool and run a query. Shopfront's server/db.js is the first line; it doesn't add the error listener.

const { Pool } = require('pg');
const pool = new Pool({ connectionString: process.env.DATABASE_URL });
pool.on('error', (err) => console.error('idle client error', err));   // otherwise an idle-connection error can crash the process

const { rows } = await pool.query('SELECT now() AS now');
console.log(rows[0].now);   // a Date

Select one row by id, and handle "not found". Compare server/routes/orders.js:10, which returns rows[0] even when it's undefined.

const { rows } = await pool.query('SELECT id, name FROM items WHERE id = $1', [itemId]);
if (rows.length === 0) return null;   // check rows.length, not rowCount
return rows[0];

Insert and get the new id back. Compare createOrder in server/routes/orders.js:6.

const text = 'INSERT INTO items(name, attrs) VALUES($1, $2) RETURNING id';
const values = ['example', { color: 'blue' }];   // a plain object is sent as JSON
const { rows } = await pool.query(text, values);
const newId = rows[0].id;                        // a string if the column is bigint/bigserial

Run a transaction. Not in Shopfront yet: an order plus stock changes would need one.

const client = await pool.connect();
try {
  await client.query('BEGIN');
  await client.query('UPDATE accounts SET balance = balance - $1 WHERE id = $2', [amount, fromId]);
  await client.query('UPDATE accounts SET balance = balance + $1 WHERE id = $2', [amount, toId]);
  await client.query('COMMIT');
} catch (err) {
  await client.query('ROLLBACK');
  throw err;
} finally {
  client.release();                      // always give the connection back
}

Turn a database error into a response (Express 4). What Shopfront's handlers are missing.

app.post('/items', async (req, res, next) => {
  try {
    const { rows } = await pool.query('INSERT INTO items(name) VALUES($1) RETURNING id', [req.body.name]);
    res.status(201).json(rows[0]);
  } catch (err) {
    if (err.code === '23505') return res.status(409).json({ error: 'duplicate' });   // SQLSTATE: unique violation
    next(err);
  }
});

Start a local database and create a table. Bind to 127.0.0.1 so it isn't reachable from your network.

docker run --name pg-local -e POSTGRES_PASSWORD=<local-password> -p 127.0.0.1:5432:5432 -d postgres
docker exec -it pg-local psql -U postgres
